# 🌊 Network Stress Simulator (DoS Tool)
Developed by **DarkVORTEX23**

A lightweight network performance testing utility designed to simulate Denial of Service (DoS) attack vectors. This tool helps network administrators and cyber security professionals stress-test firewalls, routers, and web application thresholds against flood attacks.

---

### 🛡️ Features
- Multithreaded execution for optimized throughput simulation.
- Supports UDP and TCP traffic generation.
- Configurable packet payload size and port parameters.
